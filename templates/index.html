About the Project

The Explainable AI-Based Student Performance Prediction System uses machine learning to estimate a student's final academic score based on demographic, family, social, and academic-related information.

The system uses a Gradient Boosting regression model to predict the student's final score on a scale of 0 to 20. SHAP (SHapley Additive exPlanations) is used to explain which features contributed most strongly to each prediction.

How the System Works

1

Student Data

The user provides information about the student's academic, demographic, family and social background.

2

Preprocessing

Numerical and categorical features are processed so they can be used by the machine learning model.

3

Prediction

The Gradient Boosting regression model estimates the student's final score out of 20.

4

Explanation

SHAP identifies the features that contributed most to the model's predicted score.
