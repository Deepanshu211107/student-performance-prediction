About EduPredict X

More than a predicted grade

EduPredict X is an explainable AI-based student performance prediction project. It uses demographic, family, social, and academic-related information to estimate a student's final grade.

A Gradient Boosting regression model generates the prediction on a scale of 0 to 20. SHAP (SHapley Additive exPlanations) helps explain which input features contributed to that individual result.

Important: Predictions are estimates, not guarantees of a student's actual academic outcome. SHAP explanations describe model behaviour and do not establish cause and effect.
